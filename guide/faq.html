Frequently Asked Questions
Answers to common questions about the semiconductor device parameter extractor: data privacy, supported file formats, why results differ from published values, how to cite, and how to report problems. All processing happens in the browser.

도구를 쓰면서 자주 받는 질문 열 가지를 세 갈래로 모았습니다. 더 자세한 설명은 가이드의 다른 글에 있습니다.

자료와 파일

올린 파일이 서버로 전송되나요?

아니요. 파일은 브라우저 메모리에서만 읽히고 계산되며, 어떤 서버로도 전송·저장되지 않습니다. 회원가입과 로그인도 없습니다. 브라우저 개발자 도구의 네트워크 탭을 열어 두고 파일을 올려 보면 요청이 생기지 않는 것을 직접 확인할 수 있습니다.

어떤 파일 형식을 지원하나요?

쉼표·탭·세미콜론·공백으로 구분된 텍스트 파일(CSV, TSV, TXT, DAT)과 붙여넣은 텍스트를 읽습니다. 소수점 쉼표, 주석 줄, 설명 줄이 섞인 파일도 자동으로 처리합니다. 엑셀 파일(xlsx)은 CSV 로 저장한 뒤 올려 주세요.

Keithley 4200 이나 Keysight B1500 파일이 바로 열리나요?

GateV/DrainI/DrainV 이름이 붙은 Keithley 내보내기와 DataName/DataValue 줄로 된 B1500 EasyEXPERT 내보내기를 인식하는 프리셋이 있습니다. 실제 파일은 소프트웨어 버전에 따라 모양이 조금씩 달라서, 열이 잘못 잡히면 두 번째 카드에서 직접 고르면 됩니다.

결과 해석

결과가 논문이나 다른 프로그램의 값과 다른 이유는 무엇인가요?

대부분 기법과 맞춤 구간이 다르기 때문입니다. 문턱전압은 정의가 여러 가지이고, SS 와 이동도는 어느 구간을 직선으로 맞췄는지에 따라 달라집니다. 결과표 비고에 기법, 기준 전류, 맞춤 구간, 점 수, R² 를 적어 두었으니 비교 대상과 같은 조건인지 먼저 확인해 보세요.

네 가지 Vth 중 어느 값을 써야 하나요?

목적에 따라 다릅니다. 공정 관리나 여러 소자 비교에는 정전류법(CC)이 단순하고 안정적이며, 물리 모형과 맞추려면 선형외삽법(ELR)이 흔히 쓰입니다. 어느 것을 쓰든 기법 이름과 조건(Icc, Vd, 회귀 구간)을 값과 함께 적어야 다른 자료와 비교할 수 있습니다.

이동도가 "—" 로 나오고 계산되지 않아요.

이동도 계산에는 채널 폭 W, 채널 길이 L, 산화막 두께 tox 가 필요합니다. 두 번째 카드의 소자 정보 칸에 세 값을 넣으면 Cox = ε0·εr/tox 로 산화막 정전용량을 구해 계산합니다.

정확도는 어떻게 검증했나요?

파라미터를 미리 아는 합성 곡선(EKV 식 MOSFET, 뉴턴법으로 푼 다이오드 식)에 잡음 0·1·3% 를 섞어 추출값이 허용 오차(예: ELR ±20 mV, SS ±5 mV/dec, 다이오드 n ±3%) 안에 드는지 자동으로 검사합니다. 현재 67개 항목이 통과하며, 하나라도 실패하면 새 버전이 배포되지 않습니다.

저장·인용·문의

결과를 논문이나 보고서에 어떻게 인용하나요?

도구 이름 "반도체 소자 파라미터 추출기", 주소 https://app.macultist.com/devparam/, 사용한 기법과 맞춤 조건, 사용 날짜를 적어 주시면 됩니다. 기법 자체의 근거는 원 문헌(예: Ortiz-Conde 등의 Vth 추출법 리뷰, Cheung 과 Cheung 의 직렬저항 추출법)을 인용하는 것이 맞으며, 각 글의 본문에 출처를 적어 두었습니다.

그래프와 결과표는 어떻게 저장하나요?

그래프마다 "SVG 저장" 버튼이 있어 벡터 그림 파일로 내려받을 수 있고, 결과표는 "마크다운 표 복사", "CSV 복사", "CSV 내려받기" 버튼으로 옮길 수 있습니다.

오류를 발견했거나 지원했으면 하는 장비 형식이 있어요.

macultist@gmail.com 으로 보내 주세요. 파일 형식 문제라면 소자 정보를 지운 샘플 몇 줄(헤더와 데이터 3~4줄)을 함께 보내 주시면 빠르게 확인할 수 있습니다.
